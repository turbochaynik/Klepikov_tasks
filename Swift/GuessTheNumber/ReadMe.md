# GuessTheNumber

Мини-игра на SwiftUI с MVVM.  
Пользователь угадывает число от 1 до 100.  

## Как играть

1. Вводите число в текстовое поле  
2. Нажимаете "Проверить"  
3. Система подсказывает, больше или меньше ваше число  
4. Нажмите "Заново", чтобы начать новую игру  

## Структура проекта

- Models — логика игры  
- ViewModels — связывает модель и UI  
- Views — пользовательский интерфейс
